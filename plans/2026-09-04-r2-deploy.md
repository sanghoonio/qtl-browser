# R2 data deploy

Cloudflare account "topchef", bucket `qtl-browser`.

- S3 endpoint: `https://02604ac525a365f5ff995694d8c3da5a.r2.cloudflarestorage.com`
- Public dev URL: `https://pub-50e5b2fc28324ce29d894eba50691039.r2.dev`

## Steps

1. `pipeline/config.yaml` gains an `r2:` block (bucket, endpoint, public URL, allowed origins).
2. `pipeline/upload.py`: `cors` applies the bucket CORS rule, `sync` uploads the upload set
   with `aws s3 sync` against the R2 endpoint, `check` fetches a footer range from the public
   URL and confirms 206 plus the CORS headers. Credentials come only from the environment
   (`R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`), never from a file in the repo.
3. `ui/.env.production` sets `VITE_DATA_BASE` to the public URL, so `npm run build` targets
   R2 and `npm run preview` is the end-to-end rehearsal. `VITE_DATA_BASE=` (empty) builds a
   local-data bundle.
4. Sam creates an R2 API token (Object Read & Write, this bucket only), exports the two
   variables, runs `cors`, `sync`, `check`.
5. Pages project from the GitHub repo, build command `npm run build` in `ui/`, output `dist/`.
   Then add the Pages origin to `allowed_origins` and re-run `cors`.
6. Later: custom domain on the bucket instead of r2.dev, and the Pages origin behind it.

## What this changes elsewhere

- **Every range request is a Class B operation** against 10M/month free. A gene page is 20 to
  40 requests; the landing page about 5. Nothing to do unless traffic becomes large.
- **Re-running the pipeline changes files in place**; the next `sync` re-uploads only the
  files whose size or mtime changed. Removed tables need `--delete`.
- **The manifest is the contract**: `manifest.json` is uploaded too, so the About page counts
  and table list follow the bucket, not the local build.
- **`npm run build` now targets R2 by default.** Local-data production builds need
  `VITE_DATA_BASE=` on the command line.
- **Wasm compression on Pages** is still unconfirmed; the first-visit 36 MB wasm is the
  largest transfer and is served by Pages, not R2.
